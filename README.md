# CheckpointMapper
A minimalistic app that combines Vue.js and Leaflet that lets the user see their checkpoints around the world.

## Vue Standard Setup

#### Project Setup

```sh
npm install
```

#### Compile and Hot-Reload for Development

```sh
npm run dev
```

#### Compile and Minify for Production

```sh
npm run build
```
